“Open in …” hands the file straight to the tool when it is installed, with no download step. If nothing happens, use the Download button and the steps below. 「… で開く」は、ツールがインストールされていればファイルを直接渡します（ダウンロード不要）。何も起きない場合は、ダウンロードボタンと下の手順を使ってください。

How to installインストール手順

  1. Download the .ipa with a button above. Allow the download when Safari asks; the file is saved to Files → Downloads. 上のボタンで .ipa をダウンロードします。Safari が確認を出したら許可してください。ファイルは ファイル → ダウンロード に保存されます。

  2. In the downloads list or the Files app, touch and hold the file, tap Share and choose AltStore (or SideStore / TrollStore). You can also pick the file with the + button inside the tool. ダウンロード一覧かファイル App でファイルを長押しし、共有 → AltStore（または SideStore / TrollStore）を選びます。ツール内の + ボタンからファイルを選んでもかまいません。

  3. Once installed, open IslandTray and install both shortcuts from Settings. If you used ShareToTray from an earlier build, delete it first and install it again. インストールしたら IslandTray を開き、設定 から 2 つのショートカットをインストールします。以前のビルドの ShareToTray を使っていた場合は、先に削除してから入れ直してください。

  4. On AltStore / SideStore, a free-account signature expires every 7 days. Refresh the app in the tool regularly. AltStore / SideStore では、無料アカウントの署名は 7 日ごとに期限が切れます。ツールで定期的に更新してください。

What’s new in 1.6.21.6.2 の新機能

  • iCloud Sync: another device's changes show up faster — the folder is checked every 15 seconds while the app is open, and a newly requested item is read a few seconds later instead of after a whole cycle
  • Clearer setup guide: the note on why the automation is needed now leads the steps it explains, and that section is titled for what it does — keeping the Dynamic Island always on
  • Settings: Status now sits right after Appearance
  • iCloud Sync (off by default): choose the same iCloud Drive folder on each device and the tray and clipboard are shared through it. Works on a free account. Items from another device show a cloud and download when tapped
  • Settings reordered: iCloud Sync and Updates first; each shortcut install button sits next to its guide
  • Settings → Updates always links to the GitHub releases page, for release notes and older builds
  • New setting: keep reminding about important updates (on by default). Off, an important update is offered once, like any other
  • Dragging an item out of the clipboard board no longer removes it
  • Adding through a shortcut no longer ends in a dialog: the Dynamic Island expands for a moment with a green check instead
  • The sharing question in Shortcuts remembers “Always Allow” now — reinstall both shortcuts from Settings
  • On iOS 27, the clipboard shortcut can run itself whenever you copy a screenshot; turn the automation on in Shortcuts (see Settings)
  • Search looks inside items too: what a text item says, and words recognised in images. Pick All, Names or Contents
  • An important update — an urgent fix, or one that changes how the app works — says so and keeps asking until you update
  • Folders come in from Files more reliably, and the share-sheet shortcut takes folders too (add the shortcut again from Settings). A drop that fails says why in Settings
  • Folders can go into the tray and come out as folders: drag one in from Files, or save it to On My iPhone → IslandTray. Shown with a folder icon, its own group and filter, and the total size of what is inside
  • On the clipboard board, tap an item’s name to copy it to the iPhone clipboard; swipe a row right (or all the way) to copy; in the grid, Copy is in the long-press menu. Images and files too, not just text
  • Adding through the share-sheet shortcut updates the Dynamic Island at once
  • The clipboard shortcut now says “Added to the clipboard”
  • The shortcut install buttons in Settings work again (1.1.4 shipped without the shortcuts)
  • “Remove from the tray” and “Also delete the original file” are separate settings now
  • Dragging out is always a copy, so the Files app shows the “+”
  • This page now lives on GitHub Pages; the app’s update popup opens it here
  • Files of a type iOS does not know, such as an .ipa, can be dragged into the Files app
  • The update popup on launch can skip a version: “Don’t Show Again for This Version”
  • Checks for a newer release when the app opens and brings you back to this page; turn it off or check by hand in Settings → Updates
  • “Remove from the tray once taken” is now off by default (copy, not cut); an existing choice is kept
  • iCloud 同期: 別のデバイスの変更がより速く反映されます。アプリを開いている間は 15 秒ごとにフォルダを確認し、新しい項目を要求した直後は次の周期を待たずに数秒後に読み込みます
  • セットアップの案内を分かりやすく: 自動化がなぜ必要かの説明を、それが説明する手順の先頭に移し、見出しも何のための設定かが分かる「ダイナミックアイランドを常に表示する」に変更
  • 設定:「状態」を「外観」のすぐ下に移動
  • iCloud 同期（初期値オフ）: 各デバイスで iCloud Drive の同じフォルダを選ぶと、トレイとクリップボードが共有されます。無料アカウントでも使えます。別のデバイスの項目は雲のマークが付き、タップでダウンロード
  • 設定の並びを変更: iCloud 同期とアップデートを先頭に。ショートカットのインストールボタンはそれぞれの手順の隣に
  • 設定 →「アップデート」から、いつでも GitHub のリリースページ（リリースノート・以前のビルド）を開けるように
  • 設定に「重要なアップデートを毎回知らせる」を追加（初期値オン）。オフにすると一度だけ案内します
  • クリップボードのボードから項目をドラッグで取り出しても消えなくなりました
  • ショートカットで追加したときのダイアログをやめ、ダイナミックアイランドが一瞬開いて緑のチェックで知らせます
  • ショートカットの共有確認で「常に許可」が記憶されるようになりました。設定から 2 つのショートカットを入れ直してください
  • iOS 27 では、スクリーンショットをコピーするとクリップボード用ショートカットが自動で動きます（設定に手順あり）
  • 検索が中身も対象に。テキストの本文と、画像内の文字を認識して検索できます。「すべて／ファイル名／内容」から選べます
  • 重要なアップデート（緊急の修正、使い方が変わる更新）は、その旨を表示し、更新するまで知らせ続けます
  • ファイル App からのフォルダの取り込みを改善し、共有シートのショートカットでもフォルダを送れるように（設定からショートカットを追加し直してください）。失敗したドロップは設定に理由を表示
  • フォルダをそのままトレイに入れ、フォルダのまま取り出せるように。ファイル App からドラッグするか、「このiPhone内 → IslandTray」に保存。フォルダのアイコン・専用のグループとフィルタ・中身の合計サイズで表示
  • クリップボードで項目の名前をタップすると iPhone のクリップボードにコピー。行を右にスワイプ（最後まで引くとすぐ）でもコピー、グリッドでは長押しメニューから。テキストだけでなく画像やファイルも
  • 共有シートのショートカットで追加すると Dynamic Island がすぐ更新されます
  • クリップボード用ショートカットの完了メッセージが「クリップボードに追加されました」に
  • 設定のショートカットのインストールボタンが再び動作（1.1.4 はショートカットが欠けていました）
  • 「トレイから削除」と「元のファイルも削除」を別々の設定に
  • ドラッグで取り出すときはつねにコピー。ファイル App に「+」が表示されます
  • このページを GitHub Pages に移転。アプリのアップデート通知からもここを開きます
  • .ipa など iOS が知らない種類のファイルも、ファイル App へドラッグで渡せるように
  • 起動時のアップデート通知に「このバージョンは今後表示しない」を追加
  • 起動時に新しいリリースを確認し、このページへ案内します。設定 →「アップデート」でオフにしたり手動で確認したりできます
  • 「取り出したらトレイから削除する」の初期値をオフ（切り取りではなくコピー）に変更。設定済みの値はそのまま
