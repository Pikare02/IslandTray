# ショートカット

[English](SHORTCUTS.md) · **日本語**

IslandTray はショートカットアプリに次のアクションを追加します。これらはアプリ自身の
プロセス内で動くので、共有拡張が使えない無料アカウントでも動作します。

| アクション | 内容 |
|------------|------|
| **トレイに追加** | 渡されたファイルをトレイに入れます。 |
| **クリップボードに追加** | 渡されたもの（テキスト・画像・ファイル）をクリップボードのボードに入れます。 |
| **トレイの表示を更新** | Dynamic Island の表示を作り直します。 |
| **トレイの表示をめくる** | アイランドの表示を次のページへ進めます（アイランドのボタンが使います）。 |

## 用意済みのショートカット

アプリの **設定 → セットアップ** から、どちらもワンタップでインストールできます
（シートで *ショートカット* を選び、*追加* をタップ）。署名済みなので、
「信頼されていないショートカット」の設定は不要です。

### ShareToTray — 共有シート

*共有シートからファイル・画像・メディア・PDF・テキストを受け取る → トレイに追加*

すべてのアプリの共有シートに表示されます。リンクはあえて受け付けていません。
リンクはファイルにできず、受け付けると Safari で画像を共有したときに、
ショートカットが画像ではなくリンクのほうを選んでしまうためです。

### ClipboardToTray — コピーしたものを残す

*クリップボードを取得 → クリップボードに追加*

アクションボタンか背面タップ（*設定 → アクセシビリティ → タッチ → 背面タップ*）に
割り当てれば、コピーして残すまでがワンタップになります。書式つきのテキストは受け取った
形式のまま保存され、アプリからコピーし直すと、貼り付け先が対応していれば書式ごと、
対応していなければテキストだけが渡されます。

アクションの *内容* 欄にクリップボード変数がつながっていない場合は、アクションが自分で
クリップボードを読みます。ただし iOS がそれを許すのは、IslandTray が前面にあるときだけです。

## アイランドを一日中出しておく

iOS は Live Activity を 8 時間で終了させます。毎日 3 回のオートメーションで出し直します。

1. ショートカットアプリの **オートメーション** タブで **+** をタップします。
2. **時刻** を選び、**07:00**、**毎日** に設定します。
3. **すぐに実行** を選びます。確認を求める設定のままだと、自動では実行されません。
4. アクションに **トレイの表示を更新** を選びます。
5. **15:00** と **23:00** でも同じ手順を繰り返します。

アプリを開いてもアイランドは作り直されるので、実行されなかった回があっても、
次に開いたときに元に戻ります。

## 同梱ショートカットの作り直し

`Resources/Shortcuts` の `.shortcut` ファイルは、スクリプトで生成・署名しています
（macOS のみ、`shortcuts` コマンドが必要）。

```bash
python3 scripts/make-shortcuts.py
```
